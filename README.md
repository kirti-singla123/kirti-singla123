## 🚀 Featured Projects

### 🤖 AIVA – RAG-Based AI Assistant
A full-stack AI assistant that answers questions from PDF documents using Retrieval-Augmented Generation. Documents are split into chunks, embedded with FastEmbed, and stored in a custom vector database. Questions are matched by cosine similarity, and the retrieved context goes to a Groq LLM to generate the answer. It started as a local Ollama and Gemma assistant.

**Tech:** Python · Django · Django REST Framework · React · RAG · Groq · FastEmbed · Vector Search · Prompt Engineering · Netlify · Render

[🔗 Live Demo](https://aiva-local-ai-assistant.netlify.app/) · [💻 Source Code](https://github.com/kirti-singla123/AIVA-Local-AI-Assistant)

### 📚 RAG Pipeline with Vector Database
A hands-on course lab project built with LangChain. An ingestion pipeline loads documents, splits them into chunks, generates embeddings, and stores them in a vector database. A retrieval pipeline searches the database for relevant context and passes it to an LLM to generate grounded answers.

**Tech:** Python · LangChain · Embeddings · Vector Database · Similarity Search
